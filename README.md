# MeetMux

## Overview
MeetMux is a lightweight Python project that implements the Phase 2 AI/ML engineering workstreams for Tasks 11–25. The implementation focuses on creating reusable modules for offer generation, parsing, recommendation, fairness monitoring, drift detection, and production monitoring.

## Project Structure
- `src/meetmux/` - Core package modules for the tasks.
- `tasks/` - Task-specific scaffolding and artifacts.
- `tests/` - Automated tests for the implemented behavior.
- `docs/` - Task documentation and requirements summaries.

## Installation
```bash
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
```

## Usage
Run the main task pipeline or individual modules:
```bash
python -m pytest -q
```

## Testing
```bash
python -m pytest -q
```
